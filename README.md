# Video Dataset Builder

Автоматический сборщик кинематографичных видео-клипов длительностью 1-5 секунд из YouTube и Pexels для создания датасетов машинного обучения.

## 🎯 Возможности

- **Многоисточниковый поиск**: Автоматический поиск видео на YouTube и Pexels
- **Умная обрезка**: Создание коротких клипов (1-5 сек) из случайных моментов видео
- **Детекция водяных знаков**: Автоматическое удаление видео с водяными знаками
- **Контроль качества**: Ограничение разрешения до 720p, настраиваемые параметры сжатия
- **Дедупликация**: Проверка на дубликаты по MD5 хешам
- **Многопоточность**: Параллельная обработка для ускорения работы
- **Структурированный вывод**: CSV-индекс с метаданными всех клипов

## 📋 Требования

### Системные зависимости

**FFmpeg** (обязательно):

#### Windows:
1. Скачайте FFmpeg с [официального сайта](https://ffmpeg.org/download.html#build-windows)
2. Распакуйте архив (например, в `C:\ffmpeg`)
3. Добавьте путь к `bin` папке в системную переменную PATH:
   - Откройте "Системные свойства" → "Дополнительные параметры системы" 
   - "Переменные среды" → "Path" → "Изменить" → "Создать"
   - Добавьте путь: `C:\ffmpeg\bin`
4. Перезапустите командную строку и проверьте: `ffmpeg -version`

#### Linux (Ubuntu/Debian):
```bash
sudo apt update && sudo apt install ffmpeg
```

#### macOS:
```bash
brew install ffmpeg
```

### Python зависимости

Создайте файл `requirements.txt`:

```txt
yt-dlp>=2023.12.30
opencv-python>=4.8.0
Pillow>=10.0.0
requests>=2.31.0
imagehash>=4.3.1
```

Установка:
```bash
pip install -r requirements.txt
```

```json
  "min_duration": 6,

    "enabled": true,
    "threshold": 2,
    "check_duration": 1.0
  },
  "video_quality": {
    "max_height": 720,
    "crf": 23,
    "preset": "fast",
    "audio_bitrate": "128k"
  },
  "timeout_settings": {
    "download_timeout": 120,
    "ffmpeg_timeout": 120,
    "search_timeout": 30
  }

```

#### Windows:


#### Linux/macOS:

## ⚙️ Конфигурация

### Основные параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `keywords` | Список ключевых слов для поиска | `["your_keywords"]` |
| `max_per_kw` | Максимум видео на ключевое слово | `50` |
| `clip_duration` | Длительность клипа в секундах | `5` |
| `min_duration` | Минимальная длительность исходного видео | `6` |
| `workers` | Количество потоков для обработки | `2` |
| `pexels_key` | API ключ Pexels | Обязательно |

### Детекция водяных знаков

```json
"watermark_detection": {
  "enabled": true,      // Включить/выключить проверку
  "threshold": 2,       // Чувствительность (0-10)
  "check_duration": 1.0 // Время проверки в секундах
}
```

### Качество видео

```json
"video_quality": {
  "max_height": 720,    // Максимальная высота
  "crf": 23,           // Фактор сжатия (18-28)
  "preset": "fast",    // Скорость кодирования
  "audio_bitrate": "128k" // Битрейт аудио
}
```

## 🐛 Устранение неполадок

### Проблема: "ffmpeg не найден"
**Решение**: 
- **Windows**: Убедитесь, что FFmpeg добавлен в PATH и перезапустите командную строку
- **Linux/macOS**: Установите FFmpeg через пакетный менеджер
- Проверьте установку: `ffmpeg -version`

### Проблема: "python не найден" (Windows)
**Решение**:
1. Установите Python с [python.org](https://www.python.org/downloads/)
2. При установке обязательно отметьте "Add Python to PATH"
3. Перезапустите командную строку

### Проблема: "pip не найден" (Windows)
**Решение**:
```cmd
python -m pip --version
# Если не работает, переустановите Python с галочкой "Add to PATH"
```

### Проблема: "Отказано в доступе" (Windows)
**Решение**: Запустите командную строку от имени администратора или используйте виртуальное окружение

### Проблема: "Ошибка API Pexels"
**Решение**: 
1. Проверьте правильность API ключа
2. Убедитесь, что не превышен лимит запросов (5000/месяц)

### Проблема: "Медленная работа"
**Решение**:
1. Увеличьте `workers` в config.json (осторожно с YouTube)
2. Уменьшите `max_per_kw` для тестирования
3. Используйте SSD для выходной директории

### Проблема: "Много дубликатов"
**Решение**: 
1. Используйте более специфичные ключевые слова
2. Проверьте, что детекция водяных знаков включена
3. Очистите кеш браузера YT-DLP: `yt-dlp --rm-cache-dir`

### Проблема: Кодировка символов (Windows)
**Решение**: Убедитесь, что используете UTF-8 кодировку в терминале:
```cmd
chcp 65001
```

## ⚠️ Важные замечания

- **Соблюдайте авторские права**: Используйте только для исследовательских целей или с соответствующими разрешениями
- **Лимиты API**: Pexels предоставляет 5000 бесплатных запросов в месяц
- **YouTube Terms**: Соблюдайте условия использования YouTube при работе с контентом
- **Дисковое пространство**: Рассчитывайте ~10-50MB на клип в зависимости от качества
- **Производительность**: Не устанавливайте слишком много потоков во избежание блокировки
